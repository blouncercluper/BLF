# BLOUNCER LEVEL FORGE — Revisi

Versi revisi mencakup:
- Perbaikan ruang/posisi teks karakter dan reward agar tidak bertabrakan.
- Reward yang dipasang ditampilkan pada tangan karakter sebagai item yang dipegang.
- Gudang Ilmu memakai editor teks kaya (bold, italic, underline, daftar, alignment, clear format) dan mode layar luas.
- Catatan Gudang Ilmu mendukung lampiran PDF/foto dan preview.
- Pohon Keahlian mendukung bukti foto/PDF dan preview.
- Rak Buku otomatis mengubah catatan ilmu menjadi format baca buku; tersedia Cetak/Simpan PDF.

## Cara memakai
Ekstrak seluruh isi folder ke satu folder dan buka `index.html` melalui HTTPS/localhost.
Data disimpan lokal di browser. Cadangkan data secara berkala. PDF/foto berukuran besar dapat memenuhi LocalStorage.
